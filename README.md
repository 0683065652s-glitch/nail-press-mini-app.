# NAIL.PRESS — Telegram Mini App

Міні-застосунок для оформлення заявок на набори press-on nails.

## Що вже є

- Адаптивна форма українською мовою.
- Палітра `#4D0A0A`, `#930A09`, `#FDFBE8`.
- Посилання на Instagram NAIL.PRESS у шапці та футері.
- Контактні дані, Нова пошта, 10 замірів нігтів.
- Посилання на дизайн з Instagram та/або власний опис.
- Перевірка заповнення полів.
- Надсилання заявки в Telegram адміністратору.
- Перевірка справжності `initData` Telegram на сервері.

## 1. Створи бота

1. Відкрий Telegram і напиши `@BotFather`.
2. Надішли `/newbot` і пройди кроки створення бота.
3. Скопіюй токен. Нікому його не надсилай і не вставляй у frontend.

## 2. Налаштуй проєкт

Потрібен Node.js 18 або новіший.

У папці проєкту:
```bash
npm install
```

Скопіюй `.env.example` у файл `.env` і заповни:
```env
BOT_TOKEN=токен_від_BotFather
ADMIN_CHAT_ID=твій_telegram_chat_id
PORT=3000
```

Щоб отримати особистий Telegram ID, можна написати боту `@userinfobot`.
Для отримання заявок у групу додай туди свого бота, а `ADMIN_CHAT_ID` вкажи як ID групи.

## 3. Запусти локально

```bash
npm start
```

Для локального тестування Mini App потрібен HTTPS-тунель, наприклад ngrok або Cloudflare Tunnel. Звичайний `localhost` Telegram на телефоні не відкриє.

## 4. Опублікуй застосунок

Розмісти Node.js-проєкт на хостингу з HTTPS (наприклад, Render або Railway). Додай змінні середовища `BOT_TOKEN`, `ADMIN_CHAT_ID`, `PORT` у налаштуваннях хостингу.

Після розгортання скопіюй HTTPS-адресу застосунку.

## 5. Підключи Mini App у Telegram

1. Відкрий `@BotFather`.
2. Використай `/mybots` і вибери свого бота.
3. Відкрий `Bot Settings` → `Menu Button` → `Configure Menu Button`.
4. Вкажи назву кнопки, наприклад `Оформити замовлення`.
5. Встав HTTPS-адресу застосунку.

Після цього клієнт зможе відкрити форму через меню бота.

## Важливо

- Не публікуй файл `.env` і не передавай токен бота стороннім.
- Перед запуском для клієнтів протестуй форму через Telegram на телефоні.
- Наразі форма надсилає текст заявки адміністратору. Завантаження фото, оплата, автоматичний розрахунок ціни та статуси замовлень не додані.
## Швидке розгортання на Render

У корені проєкту є `render.yaml` для налаштування Render Blueprint.

1. Завантаж проєкт у власний GitHub-репозиторій.
2. У Render вибери **New → Blueprint** та підключи цей репозиторій.
3. Під час налаштування введи `BOT_TOKEN` і `ADMIN_CHAT_ID` у секретні змінні середовища Render. Не додавай їх у GitHub.
4. Дочекайся завершення розгортання та скопіюй адресу сервісу, яка починається з `https://`.
5. Саме цю HTTPS-адресу встав у BotFather як адресу Web App / Menu Button.

Примітка: без токена бота та Telegram ID адміністраторських повідомлень заявки не надсилатимуться. Токен нікому не показуй.
